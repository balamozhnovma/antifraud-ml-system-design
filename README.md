# Anti-Fraud: ML System Design

Учебный проект: система выявления мошеннических банковских переводов.

- [Рабочий дизайн-документ](ML%20System%20Design%20Doc.md).
- [Неизменённый исходный документ](ORIGINAL.md).

## Источник и авторство

Исходный документ взят из [dmitrii-naumenko/DDC2023](https://github.com/dmitrii-naumenko/DDC2023), коммит `59af0db93f0fd794821d353579cdf250cbc7208a`. Он подготовлен для ML System Design Doc Challenge, Reliable ML, Data Fest Online 2023.

Авторы исходника: Sergey Artiukhin, Dmitriy Naumenko, Artem Savelyev, Eduard Poliakov, Sabrina Sadiekh. Исходный текст и изображения сохранены в `ORIGINAL.md` и `img/` без изменений. Авторство исходника не приписывается владельцу этого репозитория.

- [Открытые вопросы и Issues](OPEN_QUESTIONS.md).
- [Соответствие критериям и учёт ревью](CRITERIA_CHECKLIST.md).

В отдельной истории коммитов этого репозитория сначала сохранён исходник, затем внесены изменения по предоставленным критериям оценки. Проект описывает предполагаемую систему; обучения модели, доступа к банковским данным и проведённого пилота нет.

[Все 7 Issues](https://github.com/balamozhnovma/antifraud-ml-system-design/issues) содержат планы закрытия неопределённостей, сроки и необходимые роли. Численные требования в документе — учебные допущения, не измеренные показатели банка.
